# CinePlex Cinema Website

CinePlex is a group website developed as part of my Software Engineering studies at Ulster University.

## Technologies

- HTML
- CSS
- JavaScript
- jQuery

## Features

- Film listings and showtimes
- Cinema location information
- Contact page
- Checkout system
- Responsive navigation
- Interactive film-poster slideshow
- High-contrast accessibility mode
- Adjustable text size

## My Contribution

My main responsibility was developing the homepage of the website.

I worked on:

- Homepage HTML and CSS
- Film-poster slideshow
- JavaScript and jQuery functionality for the main menu
- News section
- Accessibility controls E.G high-contrast mode
## What I Learned

This project improved my understanding of front-end web development and gave me experience working collaboratively on a larger website. It also helped me develop my skills using JavaScript, jQuery, accessibility features and version-controlled project development.
